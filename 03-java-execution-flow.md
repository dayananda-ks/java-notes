# Java Execution Flow

## Overview

Java follows a two-step process to execute a program:

1. **Compilation** – Java source code is converted into Bytecode.
2. **Execution** – Bytecode is converted into Machine Code and executed by the CPU.

This process allows Java programs to run on different operating systems without changing the source code.

---

# Step 1: Write Java Source Code

The developer writes the Java program.

Example:

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }

}
```

The file is saved as:

```text
Main.java
```

This is called **Source Code**.

---

# Step 2: Compilation

The Java compiler (`javac`) compiles the source code.

Command:

```bash
javac Main.java
```

During compilation, the compiler:

- Checks syntax.
- Checks variables.
- Checks classes.
- Checks methods.
- Uses the Java Standard Library to verify built-in classes such as `System`, `String`, and `Math`.

If no errors are found, the compiler generates:

```text
Main.class
```

This file contains **Bytecode**.

---

# Step 3: Bytecode

Bytecode is the intermediate code generated by the Java compiler.

Characteristics:

- Platform Independent
- Stored inside `.class` files
- Executed by the JVM

Example:

```text
getstatic
ldc
invokevirtual
return
```

---

# Step 4: Program Execution

To run the program:

```bash
java Main
```

The JRE starts and provides:

- JVM
- Runtime Libraries

---

# Step 5: JVM

The JVM performs the following tasks:

- Loads the Bytecode.
- Verifies the Bytecode.
- Uses the runtime libraries provided by the JRE.
- Converts Bytecode into Machine Code.
- Executes the program.

---

# Step 6: Machine Code

Machine Code consists of binary instructions that the CPU understands.

Example:

```text
1010101010100011
```

The JVM generates Machine Code based on the operating system and processor.

---

# Step 7: CPU Execution

The CPU executes the Machine Code.

The result is displayed to the user.

Example Output:

```text
Hello, World!
```

# Responsibilities of Each Component

## Developer

- Writes Java source code.

---

## JDK

- Provides development tools.
- Provides the compiler (`javac`).
- Includes the JRE.

---

## Compiler (`javac`)

- Compiles `.java` files into `.class` files.
- Checks syntax and program correctness.
- Uses Java Standard Library definitions during compilation.

---

## Bytecode

- Intermediate code.
- Platform Independent.
- Executed by the JVM.

---

## JRE

- Provides the runtime environment.
- Provides the JVM.
- Provides runtime libraries.

---

## JVM

- Loads Bytecode.
- Uses runtime libraries.
- Converts Bytecode into Machine Code.
- Executes the program.

---

## CPU

- Executes Machine Code.
- Produces the program output.

# Summary

- The developer writes Java source code (`.java`).
- The JDK provides the compiler (`javac`).
- The compiler converts source code into Bytecode (`.class`).
- The JRE provides the runtime environment.
- The JRE provides the JVM and runtime libraries.
- The JVM loads and executes the Bytecode.
- The JVM converts Bytecode into Machine Code.
- The CPU executes the Machine Code and produces the output.
