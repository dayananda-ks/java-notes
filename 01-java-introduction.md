# Java Introduction

## Overview

Java is a high-level, object-oriented, platform-independent programming language developed by **James Gosling** at **Sun Microsystems** in **1995**. It is now maintained by **Oracle Corporation**.

Java is one of the most widely used programming languages for developing enterprise applications, web applications, desktop software, Android applications, cloud services, and distributed systems.

---

# Why Java?

Java follows the principle:

> **Write Once, Run Anywhere (WORA)**

A Java program can run on any operating system that has a Java Virtual Machine (JVM).

---

# Features of Java

## 1. Simple

- Easy to learn
- Easy to write
- Easy to maintain

---

## 2. Object-Oriented

Java is based on Object-Oriented Programming (OOP).

It supports:

- Classes
- Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

## 3. Platform Independent

Java programs run on multiple operating systems without changing the source code.

Supported platforms include:

- Windows
- Linux
- macOS

---

## 4. Secure

Java provides:

- Bytecode Verification : (Bytecode verification is a JVM security mechanism that checks the validity and safety of compiled bytecode before execution, preventing illegal operations and malformed or malicious bytecode from running.)
- 
- Strong Memory Management
- No Pointer Arithmetic

---

## 5. Robust

Java is reliable because it provides:

- Exception Handling
- Garbage Collection
- Strong Type Checking

---

## 6. Multithreaded

Java can execute multiple tasks simultaneously.

Examples:

- File Downloading
- Music Playback
- Background Processing

---

## 7. High Performance

Java uses the **Just-In-Time (JIT) Compiler**, which improves execution speed by compiling frequently used bytecode into native machine code during runtime.

---

## 8. Portable

Java applications can be moved between different operating systems without modification.

---

# Java Architecture

```text

          │
          ▼
```

# How Java Works

```text
Write Java Source Code
          │
          ▼
Compile using javac
          │
          ▼
Generate Bytecode (.class)
          │
          ▼
JVM Executes Bytecode
          │
          ▼
Machine Code
          │
          ▼
CPU Executes Instructions
          │
          ▼
Program Output
```

# Interview Questions

### 1. What is Java?

Java is a high-level, object-oriented, platform-independent programming language.

### 2. Who developed Java?

James Gosling at Sun Microsystems in 1995.

### 3. What is WORA?

Write Once, Run Anywhere.

### 4. Why is Java platform independent?

Because Java programs are compiled into bytecode, which is executed by the JVM on different operating systems.
