# First Java Program

## Overview

A Java program starts execution from the `main()` method. Every standalone Java application must contain a `main()` method because the JVM looks for this method to begin execution.

---

# Basic Program

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }

}
```

---

# Program Output

```text
Hello, World!
```

---

# Understanding the Program

## `public`

The `public` keyword is an **access modifier**.

It makes the class or method accessible from anywhere.

---

## `class`

A class is a blueprint for creating objects.

Every Java program must be inside a class.

Example:

```java
public class Main
```

Here, `Main` is the class name.

---

## `Main`

`Main` is the name of the class.

> **Note:** The file name and the public class name must be the same.

Example:

```text
Main.java
```

```java
public class Main
```

---

## `public static void main(String[] args)`

This is the **main method**, where program execution begins.

### `public`

Accessible from anywhere.

### `static`

Allows the JVM to call the method without creating an object.

### `void`

Indicates that the method does not return any value.

### `main`

The predefined method name recognized by the JVM.

### `String[] args`

Stores command-line arguments passed to the program.

---

# System.out.println()

```java
System.out.println("Hello, World!");
```

This statement prints text to the console.

### Components

| Component | Description |
|----------|-------------|
| `System` | A predefined class in Java. |
| `out` | Standard output stream. |
| `println()` | Prints text and moves the cursor to the next line. |

---

# Compilation

Command:

```bash
javac Main.java
```

Result:

```text
Main.class
```

The compiler converts the source code into Bytecode.

---

# Execution

Command:

```bash
java Main
```

The JVM loads the Bytecode, converts it into Machine Code, and executes the program.

---

# Rules for Java Programs

- Every Java program must be inside a class.
- The public class name must match the file name.
- Program execution starts from the `main()` method.
- Java statements end with a semicolon (`;`).
- Java is case-sensitive.

Example:

```java
Main
```

and

```java
main
```

are different identifiers.

---

# Common Mistakes

## File Name Does Not Match Class Name

Incorrect:

```java
public class Main
```

File:

```text
Program.java
```

Correct:

```text
Main.java
```

---

## Missing Semicolon

Incorrect:

```java
System.out.println("Hello")
```

Correct:

```java
System.out.println("Hello");
```

---

## Incorrect Main Method

Incorrect:

```java
public void main(String[] args)
```

Correct:

```java
public static void main(String[] args)
```

# Interview Questions

## 1. Where does Java program execution begin?

Execution begins from the `main()` method.

---

## 2. Why is the `main()` method static?

Because the JVM can call it without creating an object of the class.

---

## 3. What does `void` mean?

It indicates that the method does not return any value.

---

## 4. What is `String[] args`?

It is an array of command-line arguments passed to the program.

---

## 5. What is `System.out.println()`?

It is used to print output to the console.

---

# Summary

- Every Java program is written inside a class.
- Program execution starts from the `main()` method.
- `javac` compiles `.java` files into `.class` files.
- The JVM executes the generated Bytecode.
- `System.out.println()` is used to display output on the console.
- Java is case-sensitive, and every statement ends with a semicolon.
